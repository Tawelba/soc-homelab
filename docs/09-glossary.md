# Beginner glossary

| Term | Plain-language meaning |
|---|---|
| Agent | Small program on an endpoint that sends security data to a central platform |
| Alert | A rule-generated signal that needs validation; it is not automatically an incident |
| CIDR | Notation such as `/24` that describes the size of an IP network |
| Detection | Logic that identifies a behavior or condition in telemetry |
| DMZ | A network zone for services that should be separated from user systems |
| DNS | Service that translates names into IP addresses |
| Endpoint | A user or server system being managed and monitored |
| Firewall | Control that permits or blocks traffic based on policy |
| FIM | File integrity monitoring; records changes to selected files or directories |
| Gateway | Router a system uses to reach other networks |
| Hypervisor | Software that creates and runs virtual machines |
| NAT | Address translation used here to let lab systems update without bridging them to the home LAN |
| Negative test | A test proving normal or out-of-scope behavior does not trigger the control |
| OPNsense | The firewall/router operating system used by this lab |
| Positive test | A controlled action expected to trigger a control or detection |
| SIEM | Platform that centralizes, searches, and alerts on security event data |
| Snapshot | Point-in-time VM state used for quick rollback; not a full backup |
| Sysmon | Microsoft Sysinternals service that adds detailed Windows system events |
| Telemetry | Logs and measurements used to understand system activity |
| VLAN/zone | Logical network boundary used to separate systems by trust or role |
| Wazuh | Open-source security monitoring platform used as this lab's SIEM/XDR layer |

When a new technical term appears in the project, add it here in your own words. Being able to explain a control simply is evidence that you understand it.
