# Contributing

Use a small, auditable change process:

1. Open or describe the learning objective.
2. Create a short-lived branch such as `docs/firewall-baseline`.
3. Record the change using `templates/change-record.md`.
4. Test the affected control and its rollback.
5. Sanitize evidence and run the repository checks.
6. Commit with a clear message, for example `docs: document LAN firewall baseline`.

Do not submit offensive tooling, live malware, secrets, VM images, or evidence from systems outside the lab.
